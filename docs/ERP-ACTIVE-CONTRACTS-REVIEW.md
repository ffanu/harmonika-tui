## Contract corrections

- All41 named planner/schema/theme operations have operation_result: a named,
  bounded computation/projection with explicit planning/source-only scope. Legacy
  result remains for client compatibility. No live company mutation is inferred.
- Suggestions exclude selected modules; priority has explicit dependency-first
  ordinal rank; conflict checks reject ambiguous/invalid selections. Module scale
  is planning context, never invented automatic licensing/tier changes.
- Branding name/color/local PNG/JPG/WebP logo path and component radius/touch target
  are validated and used by generated Next source. Logo file must be supplied by
  owner, not fetched or silently claimed included.
- Actual generated tenant/FK index declarations skip redundant unique/index prefixes.
  Design is static: no production workload or performance measurement is claimed.
- All entrypoints reject malformed/duplicate/conflicting module selection, missing
  spec, nonfinite JSON, excessive nesting/node/byte/integer bounds. Existing domain
  batch/error boundaries and no-business-write flags are preserved.
- Journal aggregates now reject int64 overflow, matching invoice storage bounds.
- Catalog exposes102 callable_entrypoints and3 orchestrators without inventing
  numbered blueprint rows. Direct analysis requires input.data, now documented;
  missing data at direct plugin call raises ERPError instead of raw KeyError.
