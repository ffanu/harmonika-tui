Harmonika Terminal

TUI kustom Harmonika untuk coding, dokumen, browser QA dan tool multimodal. Konfigurasi serta token tetap tersimpan privat di perangkat pemilik.

Mulai

harmonika
harmonika doctor

Perintah harmonika tetap tersedia. Versi dasar TUI dikunci ke binary kustom 0.98.1; tidak ada pemeriksaan atau pemasangan update otomatis saat startup.

Skill

  • UI responsif dan aksesibilitas
  • Debug dengan reproduksi dan pengujian
  • Browser QA serta screenshot desktop/mobile
  • Baca/buat PDF, DOCX, XLSX, PPTX lokal; edit halaman PDF
  • Git review dan alur perubahan aman
  • Rilis manual, verifikasi, rollback

Tool

Membuat folder, pencarian web, analisis gambar, PDF teks, transkripsi audio lokal, analisis frame video, dan pembuatan gambar melalui Harmonika AI. Kemampuan mengikuti ketersediaan worker. PDF scan belum didukung; video memakai enam frame tanpa analisis suara; transkripsi maksimal 120 detik pertama.

harmonika skill documents capabilities
harmonika skill browser --url http://localhost:3000 --out /path/proyek/qa
harmonika update --check
harmonika update --apply /path/paket-rilis.zip
harmonika rollback

Update hanya menerima paket runtime bertanda tangan yang cocok dengan binary yang dikunci. Token, cookie, history dan binary upstream tidak disertakan dalam unduhan runtime.
