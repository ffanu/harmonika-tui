For any image/mockup/design request load harmonika-visual-design. Use real image generation for photos/illustration and browser-rendered PNGs plus editable source for precise UI/text. Use analyze_image **mode=vision** for visual self-review (8B local RTX), and ocr_document or mode=ocr for document extraction. Verify actual returned model, decoded dimensions, visible copy and desktop/mobile screenshots. Never treat byte size as quality or fabricate a completed file/check. Preserve job IDs when status is uncertain. RTX offline/busy errors must remain factual; do not silently substitute a different capability.

Natural bird generation uses an enforced count/anatomy gate in the owner high-profile adapter and the Linux Node RTX-first router. Publish only a passed visible-head/torso check. One correction is allowed only after a completed render is observed to be defective. An unavailable inspector, uncertain job or failed second check returns a structured error without publishing or fallback. Explicit multi-bird counts are preserved; fantasy and uncounted flocks are not claimed to pass this gate. References and other species still require their normal visual QA.

Use neutral pixel observations before comparing to the mockup brief, including front/side faces and perspective. Mark unmet or uncertain criteria honestly and revise completed renders when needed. Long images use overlapping tiles; coverage_complete=false never approves a whole page. Tile coverage is not a global composition judgment.
