# Media suite boundaries

- Own environments and loopback ports only; do not change Flux/H3/vision, drivers,
  existing browser profiles, CS/business databases or existing API contracts.
- Persist technical error codes, latency and job ownership; never prompts, transcript,
  browser cookies, customer media or credentials in logs.
- Every model must have pinned revision and SHA-256; report actual runtime readiness.
- F5-TTS official weights are CC-BY-NC-4.0: research-only, public/commercial route
  disabled unless separately licensed compatible weights have been configured.
- Browser defaults are read-only on explicit public targets, isolated temporary
  profile, bounded actions; never send messages, submit payment or export secrets.
- Real media tests before activation; fixture tests do not prove inference readiness.
