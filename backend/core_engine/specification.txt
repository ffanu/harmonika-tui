## 📋 Skill Interface Contract (Standar)

Setiap skill WAJIB punya:

```yaml
skill:
  id: "file.read"
  name: "Read File"
  description: "Baca isi file teks atau binary"
  
  input_schema:
    type: object
    properties:
      path:
        type: string
        description: "Path absolut ke file"
      encoding:
        type: string
        default: "utf-8"
    required: [path]
  
  output_schema:
    type: object
    properties:
      content:
        type: string
      size:
        type: integer
      modified:
        type: string
        format: date-time
  
  permissions:
    filesystem: ["read"]
    network: false
    shell: false
  
  rate_limit:
    calls_per_minute: 100
  
  timeout: 30s
  
  access:
    - web_ui: true
    - tui: true
    - api: true
```

## 🔒 Security & Permission Matrix

Setiap skill punya permission level:

| Level | Contoh Skill | Konfirmasi User? |
|-------|--------------|-------------------|
| 🟢 Safe | file.read, web.search, memory.get | Tidak |
| 🟡 Medium | file.write, shell.exec (read-only) | Konfirmasi pertama |
| 🟠 Risky | shell.exec (write), file.delete | Selalu konfirmasi |
| 🔴 Critical | system.screenshot, email.send, secret.get | Konfirmasi + log audit |

## 📐 Shared Backend — Web UI & TUI Pakai API yang Sama

```
Backend Service (FastAPI / Go / Rust)
├── REST API   → /api/v1/skills/{skill_id}/execute
├── WebSocket  → ws://stream (untuk streaming output)
├── MCP Server → Model Context Protocol (untuk LLM agent)
└── gRPC (internal, untuk performa tinggi)

Web UI (Next.js)
└── Pakai REST + WebSocket

Terminal TUI (Bubbletea / Ratatui / blessed)
└── Pakai REST + WebSocket juga (atau langsung gRPC)
```

**Backend-nya SATU, interfacenya BISA DUA.** ✅
