================================================================================
  PART 1: CORE ENGINE (7 FUNDAMENTAL SKILLS)
================================================================================

Core Engine adalah "OTAK" Harmonika AI. 7 skill fundamental yang MENJADI
FONDASI SEMUA PEMAHAMAN AI. Setiap interaksi user PASTI lewat 7 skill ini.

--------------------------------------------------------------------------------
1.1 SKILL 1: core.perceive (PERCEPTUAL LAYER)
--------------------------------------------------------------------------------

Tujuan: Paham SEMUA jenis input user (multi-modal)

Sub-capabilities:
  - Vision (gambar, video, screenshot)
  - Hearing (voice note, audio, music)
  - Reading (teks, dokumen, OCR)
  - Sensor (sensor data IoT, location, time)
  - Context (timestamp, sender, channel)

Interfaces:
  - core.perceive.vision_analyze(image) -> description
  - core.perceive.audio_transcribe(voice) -> text
  - core.perceive.document_parse(pdf) -> text
  - core.perceive.ocr_extract(image) -> text
  - core.perceive.video_analyze(video) -> scenes
  - core.perceive.sensor_read(data) -> structured
  - core.perceive.context_extract(input) -> metadata

Delegates to specialist:
  - VLM (Claude Vision, GPT-4V, Qwen-VL)
  - ASR (Whisper, Deepgram)
  - OCR (Tesseract, PaddleOCR)
  - Document parser (PyPDF, Apache Tika)

Why this is core:
  APAPUN input user (teks/gambar/video/voice), harus dipersepsi dulu
  sebelum bisa dipahami. Ini gerbang pertama.


--------------------------------------------------------------------------------
1.2 SKILL 2: core.understand (COGNITIVE LAYER)
--------------------------------------------------------------------------------

Tujuan: Paham MAKNA dari input yang sudah dipersepsi

Sub-capabilities:
  - Intent detection (apa maunya user)
  - Entity extraction (siapa, apa, kapan, di mana)
  - Sentiment analysis (positif/negatif/netral)
  - Emotion detection (senang/marah/sedih/bingung)
  - Language detection (ID, EN, daerah, code-switch)
  - Typo tolerance (paham kalimat typo)
  - Context tracking (multi-turn conversation)
  - Reference resolution ("dia", "itu", "yang tadi")
  - Sarcasm detection
  - Ambiguity detection

Interfaces:
  - core.understand.intent(text) -> intent
  - core.understand.entities(text) -> entities[]
  - core.understand.sentiment(text) -> sentiment
  - core.understand.emotion(text) -> emotion
  - core.understand.language(text) -> language
  - core.understand.context_resolve(input) -> resolved_context
  - core.understand.typo_correct(text) -> corrected

Delegates to specialist:
  - Text Typo Engine (untuk koreksi typo dalam/slang)
  - NLU models (spaCy, Rasa, BERT)
  - Emotion models (RoBERTa, DeepFace)

Why this is core:
  Tanpa understanding, AI cuma bisa pattern matching, bukan benar-benar
  paham apa yang user mau.


--------------------------------------------------------------------------------
1.3 SKILL 3: core.reason (REASONING LAYER)
--------------------------------------------------------------------------------

Tujuan: AI mikir logis, analisa, bukan asal jawab

Sub-capabilities:
  - Logical reasoning (deduction, induction)
  - Cause-effect analysis
  - Pattern recognition
  - Multi-step planning
  - What-if analysis
  - Trade-off analysis
  - Anti-hallucination (fact-check, verify)
  - Confidence scoring
  - Root cause analysis
  - Decision tree traversal

Interfaces:
  - core.reason.analyze(problem) -> analysis
  - core.reason.plan(goal) -> steps[]
  - core.reason.fact_check(claim) -> verified
  - core.reason.confidence(response) -> score
  - core.reason.alternatives(situation) -> options[]
  - core.reason.root_cause(symptom) -> cause

Anti-hallucination protocols:
  - NEVER invent facts
  - ALWAYS cite source
  - ADMIT when uncertain
  - ESCALATE when confidence < 60%
  - VERIFY before send

Why this is core:
  Ini yang membedakan AI pintar dengan AI bodoh. Tanpa reasoning,
  AI cuma autocomplete canggih.


--------------------------------------------------------------------------------
1.4 SKILL 4: core.retrieve (KNOWLEDGE LAYER)
--------------------------------------------------------------------------------

Tujuan: Cari tahu informasi yang tidak AI punya

Sub-capabilities:
  - Internal knowledge base search (RAG)
  - Web search (real-time)
  - User-specific data retrieval
  - Conversation history search
  - Cross-reference multiple sources
  - Citation formatting
  - Freshness check (apakah info masih update)
  - Source credibility assessment

Interfaces:
  - core.retrieve.kb_search(query) -> results
  - core.retrieve.web_search(query) -> results
  - core.retrieve.user_data(query, user) -> data
  - core.retrieve.history_search(query, session) -> matches
  - core.retrieve.cross_reference(claim) -> verified
  - core.retrieve.cite(source) -> citation

Delegates to:
  - Vector DB (Qdrant, Weaviate, Chroma)
  - Web search API (Tavily, Serper, Google)
  - PostgreSQL (user data)
  - Redis (conversation cache)

Why this is core:
  AI tidak mungkin tahu segalanya. Harus bisa cari tahu dengan cepat
  dan akurat.


--------------------------------------------------------------------------------
1.5 SKILL 5: core.decide (DECISION LAYER)
--------------------------------------------------------------------------------

Tujuan: Ambil keputusan: jawab langsung, atau rujuk ke specialist?

Sub-capabilities:
  - Decision matrix (kapan pakai core, kapan specialist)
  - Risk assessment
  - Confidence threshold check
  - Escalation trigger
  - Multi-option ranking
  - Human handoff decision
  - Crisis detection (harus human intervention)

Interfaces:
  - core.decide.route(intent, context) -> engine_choice
  - core.decide.escalate(reason) -> human_agent
  - core.decide.confidence_check(score) -> action
  - core.decide.risk_assess(action) -> risk_level
  - core.decide.crisis_detect(input) -> crisis_level

Decision matrix:
  - Confidence > 90% & simple: handle by Core
  - Confidence 70-90%: handle by Core with caveat
  - Confidence < 70%: route to Specialist
  - Crisis detected: escalate to Human immediately
  - Complex domain (legal/medical): route to Specialist

Why this is core:
  Tanpa decision layer, AI akan over-confident atau under-confident.
  Ini yang manage kapan harus minta bantuan.


--------------------------------------------------------------------------------
1.6 SKILL 6: core.act (ACTION LAYER)
--------------------------------------------------------------------------------

Tujuan: Eksekusi keputusan - generate response atau panggil tool

Sub-capabilities:
  - Text generation (response)
  - Multi-modal generation (text + image + voice)
  - Tool calling (API, function)
  - Code execution
  - File operations
  - External service integration
  - Streaming response
  - Tone adjustment
  - Personalization
  - Format adaptation (per channel)

Interfaces:
  - core.act.generate_text(prompt, context) -> response
  - core.act.generate_voice(text) -> audio
  - core.act.generate_image(prompt) -> image
  - core.act.call_tool(tool_name, args) -> result
  - core.act.execute_code(code) -> output
  - core.act.stream(response) -> stream

Delegates to:
  - LLM (GPT-4o, Claude 3.5, Llama 3.1)
  - TTS (ElevenLabs, Azure)
  - Image gen (DALL-E, Stable Diffusion)
  - Tool execution sandbox

Why this is core:
  Tanpa action layer, AI cuma bisa mikir, tidak bisa ngapa-ngapain.
  Ini yang ubah pikiran jadi kenyataan.


--------------------------------------------------------------------------------
1.7 SKILL 7: core.learn (LEARNING LAYER)
--------------------------------------------------------------------------------

Tujuan: AI makin pintar dari setiap interaksi

Sub-capabilities:
  - Interaction logging
  - Pattern detection
  - User preference learning
  - Feedback collection
  - Knowledge base update
  - Fine-tune dataset building
  - A/B testing
  - Continuous improvement
  - Drift detection
  - Model retraining trigger

Interfaces:
  - core.learn.log(interaction)
  - core.learn.detect_pattern(history) -> patterns
  - core.learn.update_preference(user, data)
  - core.learn.collect_feedback(user, response)
  - core.learn.update_kb(new_knowledge)
  - core.learn.fine_tune(dataset) -> model

Why this is core:
  AI yang tidak belajar akan ketinggalan zaman. Ini yang bikin AI
  makin pintar seiring waktu.

================================================================================
  PART 7: TRADE-OFF ANALYSIS
================================================================================

7.1 CORE ONLY (Tanpa Specialist)

  ✅ PROS:
  - Simpel, 1 engine untuk semua
  - Maintenance mudah
  - Cross-domain seamless

  ❌ CONS:
  - Tidak optimal untuk task kompleks
  - Generalist < specialist
  - Sulit tune per domain
  - Risk: 1 bug = semua affected

  Verdict: OK untuk MVP, tidak untuk production kompleks

7.2 SPECIALIST ONLY (Tanpa Core)

  ✅ PROS:
  - Optimized per domain
  - Deep capability
  - Easy tune per domain

  ❌ CONS:
  - Tidak terintegrasi
  - Data silo antar engine
  - User experience fragment
  - Maintenance banyak engine

  Verdict: Tidak recommended, user experience buruk

7.3 HYBRID (Core + Specialist) ⭐ RECOMMENDED

  ✅ PROS:
  - Best of both worlds
  - Core handle 80% umum
  - Specialist handle 20% kompleks
  - Shared memory & context
  - Scalable architecture
  - Easy add new specialist

  ❌ CONS:
  - Architecture kompleks
  - Butuh initial investment besar
  - Butuh orchestrator yang baik

  Verdict: RECOMMENDED untuk long-term

  PART 8: SARAN LENGKAP DARI SAYA
================================================================================

Setelah membangun dokumen ini, berikut saran lengkap saya:

8.1 STRATEGIC DECISIONS

  a) BUILD CORE FIRST
     - Jangan langsung bangun specialist tanpa Core
     - Core = fondasi, tanpa Core = rumah di atas pasir
     - Invest 3 bulan pertama untuk Core saja

  b) ORCHESTRATOR IS CRITICAL
     - Orchestrator yang buruk = sistem yang buruk
     - Invest waktu untuk design decision matrix
     - Test dengan banyak scenario

  c) SHARED MEMORY IS KEY
     - Jangan ada data silo antar engine
     - User profile, history, preference = shared
     - Ini yang bikin experience seamless

  d) START WITH MVP PER ENGINE
     - Jangan bangun semua 215 skill Chat Engine sekaligus
     - Bangun 15 skill MVP dulu
     - Test dengan real user
     - Iterate berdasarkan feedback

8.2 ANTI-PATTERNS (YANG HARUS DIHINDARI)

  a) OVER-ENGINEERING AWAL
     - Jangan bangun semua fitur complex di Phase 1
     - Mulai dari yang simple, iterate
     - "Ship simple, iterate fast"

  b) MONOLITH TRAP
     - Jangan bangun 1 engine raksasa untuk semua
     - Akan susah maintain, susah scale
     - Tetap pakai specialist pattern

  c) DATA SILO
     - Jangan setiap engine punya memory sendiri
     - User harus feeling 1 AI, bukan 6 AI berbeda
     - Shared memory WAJIB

  d) IGNORE ANTI-HALLUCINATION
     - Anti-hallucination BUKAN optional
     - Tanpa ini, AI akan mengarang
     - User trust akan hancur

  e) SKIP TESTING
     - Setiap engine WAJIB ada unit test, integration test
     - E2E test untuk critical path
     - Jangan ship tanpa test

8.3 BEST PRACTICE

  a) API-FIRST DESIGN
     - Semua engine expose API
     - Internal communication via API
     - Easy swap engine kalau perlu

  b) OBSERVABILITY
     - Log semua (audit trail)
     - Monitor semua (Prometheus + Grafana)
     - Trace semua (Jaeger)
     - Tanpa observability = blind

  c) GRACEFUL DEGRADATION
     - Kalau 1 engine down, sistem tetap jalan
     - Fallback ke Core
     - Circuit breaker anti cascade failure

  d) COST OPTIMIZATION
     - Cache frequent request
     - Use smaller model untuk simple task
     - Async untuk task berat
     - Monitor cost per request

  e) SECURITY FIRST
     - PII mask di log
     - Encryption at rest + in transit
     - Audit log untuk compliance
     - Pen-test berkala

8.4 LONG-TERM VISION

  Bulan 1-12: Build Core + 6 Specialist (MVP each)
  Bulan 13-24: Add Phase 2-4 skills per engine
  Bulan 25-36: Add more specialist engines (IoT, Fintech, Game, dll)
  Bulan 37+: AI Agent Swarm (multi-agent collaboration)

  - Hallucination Rate (< 2%)

================================================================================
  PART 11: ANTI-HALLUCINATION MASTER PROTOCOL
================================================================================

  Semua engine (Core + Specialist) WAJIB ikut protocol ini:

  1. CONFIDENCE THRESHOLD
     - < 50%: "Saya cek dulu" + search more
     - 50-70%: route ke specialist
     - 70-90%: jawab dengan caveat
     - > 90%: jawab confident

  2. FACT CHECK BEFORE SEND
     - Verify claim vs knowledge base
     - Web search kalau tidak ada di KB
     - Cross-reference multiple sources

  3. NEVER INVENT
     - Tidak ada fakta yang dikarang
     - Tidak ada angka yang dihapal
     - Tidak ada link yang dibuat-buat

  4. SOURCE CITATION
     - Cite sumber untuk setiap claim
     - Kalau tidak ada sumber: "setau saya"
     - Tidak ada klaim tanpa basis

  5. ADMIT UNCERTAINTY
     - "Saya tidak yakin, tapi..."
     - "Berdasarkan informasi yang ada..."
     - "Untuk kepastian, konsultasi..."

  6. ESCALATE WHEN UNSURE
     - Kalau confidence rendah → escalate
     - Kalau domain kompleks → route ke specialist
     - Kalau crisis → human intervention

  7. SCOPE LIMIT
     - Jawab hanya yang ditanya
     - Jangan out-of-scope
     - Jangan assume
