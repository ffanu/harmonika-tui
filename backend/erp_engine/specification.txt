================================================================================
     HARMONIKA AI - COMPLETE ERP ENGINE FOR ALL INDUSTRIES
          Engine ERP Cerdas yang Bisa:
          - Auto-Detect Bidang Usaha dari Spec User
          - Auto-Pilih Modul yang Relevan
          - Auto-Select Tema UI Sesuai Industri
          - Auto-Build & Deploy ERP Lengkap
          - Paham Konteks Setiap Industri (ISP, Retail, Manufaktur, dll)
          - Multi-Industry Templates (25+ industri)
================================================================================

Tujuan: Membangun ERP engine dimana Harmonika AI bisa OTONOM:
  1. Baca spec perusahaan user (nama, bidang, skala)
  2. Auto-detect industri (ISP, retail, manufaktur, jasa, dll)
  3. Auto-pilih modul yang relevan untuk industri tersebut
  4. Auto-select tema UI/UX yang sesuai (warna, layout, terminology)
  5. Auto-generate database schema
  6. Auto-build frontend + backend
  7. Auto-deploy ke server
  8. Auto-configure integrasi (payment, WA, email, dll)
  9. Hasil: ERP ready-to-use khusus untuk perusahaan tersebut
